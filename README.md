# Stealth Web Scraper Pro (Anti-Bot Evasion) 🚀

An advanced, production-ready Python web scraper designed to extract product data from dynamic, JavaScript-heavy websites while seamlessly bypassing advanced anti-bot protections (Cloudflare, PerimeterX, and Akamai).

## 🌟 Key Features
- **Stealth Execution:** Spoofs browser fingerprints, user-agents, and headers to mimic real human behavior.
- **Dynamic Content Handling:** Powered by Playwright to extract data from heavy asynchronous sites.
- **Smart Proxy Rotation:** Built-in logic for rotating residential proxies to avoid IP bans.
- **Auto-Export:** Cleans and exports structured data instantly into Excel/CSV and cloud databases.

## 🛠️ Tech Stack
- **Language:** Python 3.10+
- **Libraries:** Playwright, BeautifulSoup4, Pandas, Requests
- **Architecture:** Modular Object-Oriented Programming (OOP)
